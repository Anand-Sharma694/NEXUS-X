# 5-minute office demo

1. Open the home dashboard and explain: “NEXUS-X converts messy work into decisions.”
2. Click Analyze and run the preloaded college event example.
3. Show deadline, team, work map, risks and actions.
4. Open AI Copilot and type: “We have 4 people, too many features and 12 days. What should we cut?”
5. Open What-If is represented in the backend API; explain the next UI expansion.
6. Open Project Builder and enter: “Build a student attendance management website with login and reports.”
7. Generate the starter project and download the ZIP.
8. Show Signal Lab and explain the connection to operational/IoT monitoring.
9. Finish on Plans: Free → Pro → Enterprise.

## Important wording

Say “MVP / prototype” for the local version. Do not claim that cloud billing, SSO or autonomous production deployment are already complete.
