# Phase 3 Office Demo

1. Login with the demo account.
2. Open the Team page and add a member.
3. Edit availability/workload and show the capacity bar.
4. Open Tasks and mark a task BLOCKED.
5. Open Monitor and show the generated alert.
6. Mark the notification read.
7. Return to Dashboard and show the unread count/decision summary changed.
8. Log out.
9. Create a new Free account from the Login dialog.
10. Explain that project access is server-side isolated by owner/member/admin role.
11. For an admin-only demonstration, use the user management API to change a user's plan/role.
